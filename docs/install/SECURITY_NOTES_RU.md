# Безопасность и границы проверки

* `.env` и начальные credentials создаются с правами 0600. Они не входят в архив. Ранее опубликованный WEBUI_SECRET_KEY необходимо заменить на действующем сервере; опубликованные GitHub PAT следует отозвать. Не пересылайте дампы `.env` или `docker compose config` без удаления значений секретов.
* WebUI в новом Compose требует авторизацию; пароль первичного администратора генерируется отдельно. Он доступен только на loopback. Для доступа с ПК можно использовать SSH tunnel; публичный reverse-proxy к WebUI в пакет не добавлен.
* `--tls off` — незашифрованный HTTP. Наличие открытого порта 443 не означает доверенный TLS. До ввода реальных персональных/коммерческих данных нужен HTTPS и проверка браузером с внешней сети.
* Caddy/NGINX/MinIO имеют настоящие HTTP healthchecks. `healthy` не означает проверку регистрации, оплаты, BIM, RAG, прав всех ролей или всей бизнес-логики.
* Автоматическая диагностика не выключает firewall/SSH, не останавливает AnyRest и другие чужие контейнеры и не выполняет `docker compose down -v`. При занятости порта в HTTP-режиме выбирается свободный порт с записью в отчёт, либо применяется `--port-policy fail`.
* SQL dump + isolated restore drill проверяют базу. Для production нужен отдельный согласованный backup/restore файлов MinIO, marketplace uploads, WebUI, ключей/конфигураций. Повторный запуск/перезагрузка ОС и восстановление всех этих данных в текущей среде не проверены.
* Унаследованные Go compatibility modules в third_party — небольшие собственные реализации используемого API, не полные официальные pgx/Cobra/YAML. В драйвере исправлен простой протокол для SQL без параметров. Этот стек требует дополнительного production-аудита; его нельзя выдавать за upstream pgx.
* Бинарники в этом архиве собраны доступным Go 1.23.2. Перед production-релизом следует пересобрать поддерживаемым Go toolchain и провести актуальный dependency/CVE-аудит. Next обновлён с 14.1.0 до опубликованного vendor patch 14.2.35; это не заявление о полном security-аудите всех зависимостей на сентябрь 2026 года. Python зависимости сохраняют исходные pinned versions.
