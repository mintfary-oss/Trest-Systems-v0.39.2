# Обновление существующего сервера 217.198.12.184

**Не распаковывайте новый архив поверх работающего /opt/trest-systems.** Сначала храните его в отдельном каталоге. `install.sh --update` делает резервную копию PostgreSQL и конфигурации, но останавливается ДО копирования файлов, если обнаружит старые таблицы магазина в `public` без схемы `marketplace`.

Это намеренная защита данных, а не обещание бесшовного обновления старой схемы. В v0.39.1 Python-магазин и Go API делили `users`, `orders`, `order_items`, хотя модели несовместимы: магазин ожидает целочисленные идентификаторы, Go — UUID и строительные заказы. Одной колонки `users.is_active` недостаточно для полной совместимости.

В v0.39.2 новые установки используют `marketplace.*`. Автоматический перенос старых коммерческих данных не выполняется: нужно сопоставление пользователей/заказов, сверка объёмов, пробное восстановление и проверка логина на копии. Существующие таблицы и volumes не удаляются. PostgreSQL dump сохраняется в /var/lib/trest-systems/backups; он содержит базу, но не заменяет резервирование MinIO и загруженных файлов.

Для новой чистой установки используйте install.sh. Для текущего сервера сохраните работающую конфигурацию и образы. Пересоздание работающего v0.39.1 без проверки новой версии не требуется.

Проверки `healthy` и HTTP 200 из журналов 5 сентября 2026 года относятся к вручную восстановленному v0.39.1, а не к end-to-end подтверждению нового архива.
