# LEGAL EVIDENCE CHECKLIST — TREST SYSTEMS

## Цель

Подготовка доказательственного пакета для IP due diligence, инвестора, патентного поверенного, юриста и возможного судебного спора.

## A. Авторство

- [ ] Подписанная декларация автора/правообладателя.
- [ ] Перечень всех исходных проектов.
- [ ] Перечень авторов/участников разработки.
- [ ] Даты создания ключевых версий.
- [ ] Первые Git commits.
- [ ] Полная история Git.

## B. Контроль аккаунтов

- [ ] Репозитории принадлежат правообладателю.
- [ ] Домены принадлежат правообладателю.
- [ ] CI/CD аккаунты принадлежат правообладателю.
- [ ] Облачные/локальные registry принадлежат правообладателю.
- [ ] Секреты и recovery-коды не включены в публичные материалы.

## C. Open Source

- [ ] Прямые зависимости.
- [ ] Транзитивные зависимости.
- [ ] SPDX identifier каждой лицензии.
- [ ] LICENSE/NOTICE соблюдены.
- [ ] SBOM сохранён для каждого релиза.
- [ ] Проверены copyleft-обязательства.

## D. AI

- [ ] Сохранены существенные AI-сессии.
- [ ] Зафиксирован human review.
- [ ] Зафиксированы версии релизов.
- [ ] Нет утверждения, что AI является автором.
- [ ] Проверены условия использованных AI-сервисов на соответствующие даты.

## E. Судебная целостность

- [ ] SHA-256 каждого релизного архива.
- [ ] Read-only копия исходного репозитория.
- [ ] Экспорт Git history.
- [ ] Дата фиксации.
- [ ] Независимое хранение контрольных хэшей.
- [ ] По необходимости — нотариальное/иное допустимое удостоверение.

## F. Патент

- [ ] Выделено техническое решение.
- [ ] Составлена patent disclosure.
- [ ] Проведён prior-art search.
- [ ] Определены страны подачи.
- [ ] Проверены сроки раскрытия до подачи.
- [ ] Патентный поверенный подтвердил стратегию.
