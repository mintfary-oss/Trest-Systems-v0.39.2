# Proektirovka-sdaniy

Программа для автоматической генерации строительных чертежей в формате DXF.

**Язык:** Go  
**Выходной формат:** DXF R2000 — открывается в AutoCAD, КОМПАС-3D, NanoCAD, ZWCAD, BricsCAD, FreeCAD, LibreCAD

## Применяемые стандарты

| Стандарт | Описание |
|----------|----------|
| ГОСТ Р 21.101-2020 | Основные требования к проектной документации |
| ГОСТ 21.501-2018 | Правила выполнения архитектурных чертежей |
| ГОСТ 21.201-2011 | Условные обозначения элементов зданий |
| ГОСТ 2.303-68 | Типы линий |
| ГОСТ 2.304-81 | Шрифты чертёжные |
| ГОСТ 21.204-93 | Условные обозначения на генплане |
| СП 152.13330.2018 | Здания федеральных судов |

## Установка и запуск

```bash
# Сборка
go build -o gencad ./cmd/generate

# Генерация чертежей по конфигу
./gencad --config configs/court_tosno.yaml --out ./output

# Или через go run
go run ./cmd/generate --config configs/court_tosno.yaml --out ./output
```

## Генерируемые чертежи

| Марка | Наименование | Масштаб |
|-------|-------------|---------|
| ОД-1 | Общие данные. Перечень чертежей. ТЭП | — |
| СПОЗУ-1 | Схема планировочной организации ЗУ | 1:500 |
| АР-1 | План 1-го этажа | 1:100 |
| АР-2 | Типовой план этажей | 1:100 |
| АР-3 | Фасад главный | 1:100 |
| АР-4 | Разрез 1–1 | 1:100 |
| АР-5 | План кровли | 1:200 |
| КР-1 | Схема расположения фундаментов | 1:100 |

## Структура проекта

```
cmd/generate/        — точка входа (CLI)
pkg/dxf/             — DXF R2000 writer (чистый Go)
pkg/gost/            — рамка A1, основная надпись ГОСТ Р 21.101-2020
pkg/building/        — модель данных здания
pkg/drawings/        — генераторы чертежей
configs/             — YAML-конфиги объектов
output/              — сгенерированные DXF-файлы
```

## Конфигурация объекта (YAML)

Здание описывается в YAML-файле. Пример: `configs/court_tosno.yaml`

```yaml
building:
  name: "Здание Тосненского городского суда"
  floors: 6
  basement: true
  width_m: 48.0
  depth_m: 30.0
  floor_height_m: 3.6
  wall_ext_m: 0.40
  wall_int_m: 0.25
  wall_prt_m: 0.12
```

## Формат DXF

Программа пишет DXF R2000 (AC1015) ASCII формат напрямую без внешних библиотек.
Поддерживаются слои, типы линий, толщины линий, штриховки, текст, размеры.
